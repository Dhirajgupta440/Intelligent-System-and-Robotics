
# 🤖Intelligent Systems and Robotics (ISR) Lab

Welcome to the **Intelligent Systems and Robotics (ISR) Lab** repository! This repository contains Python implementations of laboratory experiments related to intelligent systems, robotics, control systems, computer vision, voice recognition, and autonomous navigation.

The repository is maintained for academic learning, practical implementation, and reference.

## 🧪 Experiments Overview

### ✅ Experiment 1: Path Planning Algorithms
**File:** `experiment1.py`

**Objective:** To understand path planning techniques used in intelligent systems and robotics.

**Description:**
- Study path planning in a given environment.
- Understand how search algorithms can find paths from a starting point to a destination.
- Explore obstacle avoidance and route optimization.

### ✅ Experiment 2: PID Control
**File:** `experiment2.py`

**Objective:** To understand the working of a Proportional-Integral-Derivative (PID) controller.

**Description:**
- Study the proportional, integral, and derivative terms.
- Understand error correction and feedback control.
- Explore how PID controllers help maintain a desired system response.

### ✅ Experiment 3: SLAM (Simultaneous Localization and Mapping)
**File:** `experiment3.py`

**Objective:** To understand the concept of Simultaneous Localization and Mapping in robotics.

**Description:**
- Learn how a robot estimates its position while building a map of its environment.
- Understand the relationship between localization and mapping.
- Explore the role of SLAM in autonomous navigation.

### ✅ Experiment 4: Reinforcement Learning for Robot Navigation
**File:** `experiment4.py`

**Objective:** To explore reinforcement learning techniques for autonomous robot navigation.

**Description:**
- Understand the interaction between an agent and its environment.
- Learn about states, actions, rewards, and penalties.
- Explore how an agent can learn a navigation strategy through experience.

### ✅ Experiment 5: Object Detection and Recognition
**File:** `experiment5.py`

**Objective:** To understand object detection and recognition techniques used in intelligent systems.

**Description:**
- Study how objects can be identified in images or visual input.
- Explore computer vision concepts for object recognition.
- Understand the applications of visual perception in robotics.

### ✅ Experiment 6: Voice Command Recognition
**File:** `experiment6.py`

**Objective:** To develop an understanding of voice command recognition using Python.

**Description:**
- Capture or process speech input.
- Convert speech into recognizable text using speech recognition tools.
- Understand how voice commands can support human-computer and human-robot interaction.

### ✅ Experiment 7: Gesture Recognition
**File:** `experiment7.py`

**Objective:** To understand gesture recognition and its applications in intelligent systems.

**Description:**
- Explore the recognition of human gestures using visual input.
- Understand how gestures can be interpreted as commands.
- Study the potential use of gesture-based interfaces in robotics.

*Note: The experiment descriptions summarize the topics. Refer to each Python file for its actual implementation and algorithms.*

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or later
- Git
- Visual Studio Code or another Python-compatible editor

### 1. Clone the Repository

```bash
git clone https://github.com/Dhirajgupta440/Intelligent-System-and-Robotics.git
```

### 2. Navigate to the Project Directory

```bash
cd Intelligent-System-and-Robotics
```

### 3. Install Dependencies

Install only the libraries required by the experiment you want to run.

For example, for speech recognition:

```bash
python -m pip install SpeechRecognition
```

Other experiments may require additional libraries, depending on their implementation.

### 4. Run an Experiment

For example, to run Experiment 3:

```bash
python experiment3.py
```

To run Experiment 6:

```bash
python experiment6.py
```

Replace the filename with the experiment you want to execute.
